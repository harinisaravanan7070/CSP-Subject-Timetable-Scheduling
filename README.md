# CSP-Based Subject Timetable Scheduling

## Objective

Create a valid subject timetable using a **Constraint Satisfaction Problem (CSP)** and **Backtracking**.

## CSP Structure

* **Variables:** Maths, Python, DBMS, AI
* **Domains:** 9:00 AM, 11:00 AM, 2:00 PM
* **Constraints:** Maths ≠ Python, DBMS ≠ AI
* **Algorithm:** Backtracking

## Output

The program assigns each subject a time slot while satisfying all constraints.

## Technology

* Python
* CSP
* Backtracking
